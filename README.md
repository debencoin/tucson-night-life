# Tucson Night Life

Clickable prototype of the Tucson Night Life app: member, promoter, venue owner, staff, DJ and security dashboards in one page.

- Open `index.html`, or visit the GitHub Pages site for this repo.
- Everything runs in the browser. Sign-in, payments, Stripe connections, push alerts and transfers are simulated, and data is saved only on the device you use.
- Venues other than OVIA Lounge, revenue figures and guest names are sample data.
